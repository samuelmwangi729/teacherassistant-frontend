# Teacher Assistant Frontend

The **Teacher Assistant Frontend** is a React application built with Vite that allows users to upload Excel and Word files, sends them to a backend server, and displays the extracted styles from the files. The styling of the frontend is done using **Tailwind CSS** for a responsive and modern UI.


## Technologies

- **React**: JavaScript library for building user interfaces.
- **Vite**: A fast build tool and development server.
- **Tailwind CSS**: Utility-first CSS framework used for styling the UI.
- **Axios**: For making HTTP requests to the backend.

## Installation

1. **Clone the repository:**

   ```bash
   git clone https://github.com/samuelmwangi729/teacherassistant-frontend.git
   cd teacherassistant-frontend
2. **installing depedencies**
    ```bash 
    cd teachersassistant-frontend
    npm install
3. **running development server**
    ```bash 
    npm run dev
